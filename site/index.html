О проекте

Справочник собран из исходников (github.com/ArduPilot/ardupilot). Тексты сообщений берутся автоматически из вызовов GCS_SEND_TEXT, send_text, check_failed и pre-arm проверок библиотек (с тем префиксом PreArm: …, который реально добавляет прошивка), а строковые константы подставляются из кода.

Из кода (автоматически): текст сообщения, файл и строка, условие if (…), при котором оно выводится, бит ARMING_CHECK. Описания, диапазоны и значения параметров взяты из официальной базы параметров Copter (apm.pdef.json, генератор ArduPilot param_parse.py).

Сверено с кодом: причины и шаги для всех предупреждений и ошибок, актуальных для Copter, написаны вручную по коду этой версии: пороги, условия и значения параметров взяты из исходников. Под каждым разбором указана функция, по которой он написан. Все упомянутые параметры при сборке автоматически проверяются: существуют ли они в 4.6.3 и не переименованы ли.

Информационные сообщения и сообщения других типов аппаратов показаны без ручного разбора: только условие из кода.

⚠ Отключение проверок (ARMING_CHECK, failsafe) убирает защиту. Используй только для стендовых тестов без пропеллеров.

Обновление под новую версию прошивки описано в README репозитория.
