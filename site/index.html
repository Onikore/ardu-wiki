О проекте

Справочник собран автоматически из исходников (github.com/ArduPilot/ardupilot): все вызовы GCS_SEND_TEXT, send_text, check_failed и сообщения проверок (failure_msg) в ArduCopter/ и libraries/.

Для каждого сообщения показаны: шаблон текста (%u, %s — подставляемые значения), файл и строка в исходниках, фрагмент кода с условием срабатывания и параметры, которые упоминаются рядом, вместе с описаниями из исходников.

Причины и шаги решения написаны вручную по документации и коду. Там, где разбора пока нет, показано условие из кода и общая подсказка по подсистеме: именно оно говорит, почему сообщение появилось.

Всегда сверяйся с логом полёта и официальной документацией: ardupilot.org/copter, форум discuss.ardupilot.org.

⚠ Отключение проверок (ARMING_CHECK, failsafe) убирает защиту. Используй только для стендовых тестов без пропеллеров.

Обновление данных под новую версию: python build/build.py src/ap site (см. README в репозитории).
